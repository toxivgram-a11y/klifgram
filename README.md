# Klifgram NFT Depot

Веб-интерфейс депо с играми, NFT-коллекциями и ручной проверкой заявок.

## Запуск

Открой `index.html` в браузере или используй любой статический HTTP-сервер. Node.js в текущем окружении не установлен, поэтому проект не требует сборки и зависимостей.

## Внутри

- разделы Игры, Пополнение, Вывод и Профиль;
- игры Мины, Краш и Апгрейд;
- история игр и локальный баланс;
- загрузка фото или видео подтверждения;
- лимит 5 заявок за 30 минут;
- состояния заявок на проверке.

Коллекции на главной странице являются описанием ассортимента. Для подключения реальных Telegram NFT нужны API форка, backend, авторизация, серверная проверка подарка, база данных, журнал транзакций и админ-подтверждение.
