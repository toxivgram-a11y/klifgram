# Klifgram NFT Depot

Веб-интерфейс депо с играми, NFT-коллекциями и ручной проверкой заявок.

## Запуск

Для статического просмотра открой `index.html` или используй любой HTTP-сервер. Для серверной админки запусти Node API:

```powershell
$env:ADMIN_TOKEN = "замени-на-длинный-секрет"
node server.js
```

После запуска админка доступна на `/admin.html`. Введённый token передаётся в API-запросах, а начисления и подтверждения сохраняются в `data/store.local.json`. GitHub Pages не запускает Node API, поэтому для работы серверных операций нужен Node-хостинг.

## Внутри

- разделы Игры, Пополнение, Вывод и Профиль;
- игры Мины, Краш и Апгрейд;
- история игр и локальный баланс;
- загрузка фото или видео подтверждения;
- лимит 5 заявок за 30 минут;
- состояния заявок на проверке.

Коллекции на главной странице являются описанием ассортимента. Для подключения реальных Telegram NFT нужны API форка, серверная авторизация, проверка подарка, база данных, журнал транзакций и админ-подтверждение.
