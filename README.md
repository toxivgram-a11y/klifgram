# NFT Depot Demo

Статический MVP интерфейса депозита с тестовыми кредитами.

## Запуск

Открой `index.html` в браузере или используй любой статический HTTP-сервер. Node.js в текущем окружении не установлен, поэтому проект не требует сборки и зависимостей.

## Внутри

- разделы Игры, Пополнение, Вывод и Профиль;
- демо-игры Мины, Краш и Апгрейд;
- история игр и локальный тестовый баланс;
- загрузка изображения подтверждения;
- лимит 5 заявок за 30 минут;
- состояния заявок на проверке.

Реальные деньги, Telegram NFT, OCR, авторизация, админ-подтверждение и выплаты намеренно не подключены. Перед production нужно добавить backend с авторизацией, базой данных, серверной генерацией результатов, журналом транзакций и юридической проверкой gambling-функций.
